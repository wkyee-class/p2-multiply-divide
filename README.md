# 乘和除的關係

小二乘和除的關係課堂遊戲

網站發布後，請用 GitHub Pages 網址開啟：
https://wkyee-class.github.io/p2-multiply-divide/

## 怎樣用

- 學生與老師用同一個網站。首頁有「學生」和「老師」兩個按鈕。
- 學生：點選自己的學號（1–40），再輸入老師顯示的四位課堂編號，然後作答並按「提交」。課堂上不會顯示對錯或正確算式。網絡不穩時可選「單機練習／自己溫習」。
- 老師：登入後建立或重開課堂，把課堂編號投影給學生。控制台可看誰在線、誰已提交、做到第幾題，亦可點開作品、廣播討論、控制下一題、開新一輪和匯出資料。老師入口也可開啟：https://wkyee-class.github.io/p2-multiply-divide/teacher.html

四題為 8 個蘋果、12 個蛋糕、20 支鉛筆、24 個皮球，適合 iPad 觸控畫環線。
